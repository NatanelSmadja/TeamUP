# TEAMUP • אפיון UI UX מלא

## עיקרון המוצר

המשתמש צריך להבין בתוך שנייה אחת מה מצב המשחק, מה נדרש ממנו ומה יקרה בהמשך. לכן מצב המשחק מופיע בכל מסך כרצף אחד ברור:

הרשמה פתוחה ← קבוצות פורסמו ← משחקים עכשיו ← דירוגים פתוחים ← סיכום מוכן

בכל שלב משתנים הכותרת, הפעולה הראשית והתוכן שמקבל קדימות. בזמן הרשמה הפעולה היא אישור הגעה. אחרי פרסום קבוצות הפעולה היא פתיחת ההרכב. בזמן המשחק נפתח לוח חי. לאחר המשחק עוברים לדירוגים ולבסוף לסיפור הערב.

## מרכז המשחק

מרכז המשחק מחולק לחמישה אזורים קבועים. המשתמש נשאר באותו הקשר ולא צריך ללמוד מסך חדש בכל שלב.

| אזור | מידע ופעולות |
| --- | --- |
| סקירה | מצב הרשמה, קיבולת, רשימת המתנה, סגל ושלבי המשחק |
| קבוצות | חלוקה, ממוצע דירוג, עמדות, שוער וקפטן |
| מגרש חי | טיימר משותף, תוצאה, שערים, אישורים, ניצחונות ושערים נקיים |
| סיכום | סיפור המשחק, MVP, מספרים, כובשים ורגעים |
| דירוגים | ציונים אישיים, התקדמות ובחירת MVP |

### הרשמה ונוכחות

1. המשחק מציג כמה מקומות נשארו ומה מועד סגירת ההרשמה.
2. אישור הגעה משנה את המסך מיד ומסביר שהמקום נשמר.
3. כאשר הסגל מלא, שחקן חדש עובר לרשימת המתנה ורואה את מקומו בתור.
4. מנהל יכול לסמן נוכחות ליחיד או לכולם, להוסיף אורח ולנהל רישום ידני.
5. אחרי תחילת המשחק הנוכחות ננעלת כדי לשמור על תקינות הנתונים.

### חלוקת קבוצות

1. החלוקה שומרת על גודל הקבוצה שהוגדר.
2. אם נרשמו 12 שחקנים למשחק של 3 קבוצות בגודל 5, החלוקה היא 5, 5, 2.
3. האיזון מתחשב בדירוג, עמדה ושוערים.
4. מנהל יכול להעביר, להחליף, לנעול שחקן, לבטל שינוי ולחלק מחדש.
5. פרסום ההרכבים שולח עדכון ומעביר את המשחק לשלב הבא.

### מגרש חי

1. הטיימר משותף לכל הצופים ומציג ריצה, עצירה, המשך, סיום ואיפוס.
2. שחקן מדווח שער לאישור. מנהל יכול לאשר, לדחות או להוסיף שער מאושר ישירות.
3. רק שחקן שסומן כנוכח יכול להיבחר כמבקיע.
4. בסוף כל משחקון מנהל מוסיף ניצחון לקבוצה.
5. אחרי ניצחון בלי ספיגה אפשר להוסיף שער נקי ולבחור את השוער.
6. כל פעולה מופיעה ביומן האירועים לפי זמן.

### סיום ודירוגים

1. לפני סיום המשחק המערכת בודקת שאין דיווחים פתוחים.
2. הנוכחות והקבוצות ננעלות.
3. נוצר סיכום עם תוצאה, כובשים, ניצחונות, שערים נקיים וסיפור קצר.
4. חלון הדירוגים נפתח לזמן מוגדר.
5. כל שחקן נותן ציון ובוחר MVP אחד.
6. אחרי הסגירה מתפרסמים ממוצעים והמצטיין נכנס לפרופיל ולהיסטוריה.

## חוויית מובייל

1. ארבעת היעדים השכיחים נמצאים בתחתית: בית, המשחק הפעיל, כל המשחקים וסטטיסטיקות.
2. כל שאר המסכים נמצאים בתפריט ״עוד״ שנפתח כגיליון מלא.
3. בראש התפריט מופיע קיצור קבוע לפרופיל האישי.
4. המסכים בתפריט מסודרים לפי המשחק שלי, הקבוצה, החשבון שלי וניהול.
5. חיפוש בתפריט מאפשר להגיע ישירות לכל אזור לפי השם או התיאור שלו.
6. כפתור הפעולה הראשי מקבל רוחב מלא כשאין מקום בטוח להצגה לצד תוכן.
7. כרטיסי משחק וקבוצה הופכים לעמודה אחת.
8. סגל ונתונים נשארים בשתי עמודות רק כאשר התוכן נשאר קריא.
9. אזורי גלילה אופקית מוגבלים ללשוניות ולבחירת ימים.
10. אזור הניווט מתחשב בשטח הבטוח של מכשירי iPhone.

## גבולות ההדמיה

ההדמיה משתמשת בנתוני דוגמה מקומיים ואינה כותבת למסד הנתונים. פעולות כמו שליחת התראה, יצירת משחק, התקנת אפליקציה, הורדת באנר ושינוי הרשאות מציגות את הזרימה והמשוב בלבד. הטמעה באתר הפעיל תתבצע רק לאחר אישור הכיוון.
